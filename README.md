# Scrum Situation RAG

A retrieval-augmented generation (RAG) tool for answering Scrum and agile questions grounded strictly in official Scrum.org guides. No hallucination — every answer cites the exact passage it came from.

**Live demo →** [rishendra125.github.io/scrum-situation-rag](https://rishendra125.github.io/scrum-situation-rag)

![Scrum Situation RAG — working demo](Working%20demo.png)

---


## What it does

You type a question about a Scrum situation — a blocked team, a conflict between roles, unclear accountability — and the app:

1. Retrieves the most relevant passages from the source guides
2. Sends those passages to Claude along with your question
3. Returns an answer with citations, so you can verify every claim

Works entirely in the browser — no backend, no server, no data leaves your device except the call to generate the answer.

---

## Modes

### Demo Mode
No API key needed. Four preset questions have pre-computed answers baked in. Toggle **Demo Mode** on in the sidebar and pick a preset question. Instant answer, no key required — useful for a quick look before committing to a key.

### BYOK (Bring Your Own Key)
Paste your [Anthropic API key](https://console.anthropic.com/) into the sidebar. The key is stored in your browser's `localStorage` — it persists across page reloads and is never sent anywhere except Anthropic's API. Click **Clear** to remove it.

### claude.ai (automatic)
When opened directly on claude.ai, the app uses the built-in sample capability — no key, no demo mode needed.

## Source Guides

The app searches across these official Scrum.org documents:

- **The Scrum Guide** (2020) — Ken Schwaber & Jeff Sutherland
- **The Kanban Guide for Scrum Teams**
- **Evidence-Based Management (EBM) Guide**
- **The Agility Guide to Scrum at Scale**

## Search Depth (Chunking Strategies)

Controls how the source text is split before retrieval:

| Strategy | How it works | Best for |
|---|---|---|
| **Simple Fixed-Size** | Splits text into fixed-size blocks | Fast scan, may cut mid-sentence |
| **Fixed Parent-Child** | Matches a small unit, returns the full surrounding section | Precise match with full context |
| **Recursive Parent-Child** | Splits at natural section boundaries | Complete, coherent passages — recommended |

## Sidebar Controls

- **Demo Mode** — Toggle pre-computed answers on/off (no key needed)
- **API Key** — Your Anthropic API key (stored in browser localStorage, never transmitted elsewhere)
- **Situation Filter** — Narrow retrieval to chunks tagged for your situation: Blocked, Conflict, Uncertainty, Momentum, Accountability, Clarity
- **Search Depth** — Choose chunking strategy (see above)
- **Sources to review** — Number of passages retrieved before generating the answer (slider)

## How to use

**With Demo Mode:**
1. Toggle **Demo Mode** on in the sidebar
2. Pick one of the four preset questions
3. Click **Ask** — answer appears instantly, no key needed

**With your own key:**
1. Paste your Anthropic API key in the sidebar and click **Save Key**
2. Optionally select a situation filter
3. Choose a Search Depth (Recursive Parent-Child recommended)
4. Type your question or pick a preset
5. Click **Ask**
6. Review the answer and expand the Sources section to verify citations

## RAG Pipeline

Every query runs through 4 steps shown in the pipeline panel:

| Step | What happens |
|---|---|
| **1. Finding Relevant Passages** | Cosine similarity search across all chunks to find the closest matches |
| **2. Combining Search Results** | Best passages selected from combined rankings |
| **3. Ranking by Relevance** | Re-ranking pass to reorder passages by true relevance to the question |
| **4. LLM Generation** | Final answer generated by Claude using the top-ranked passages |

The total time is shown at the bottom (typically 3–6 seconds depending on passage count and answer length).

---

## Sources Table

After each answer, the Sources section shows a detailed breakdown of what was retrieved:

| Column | Meaning |
|---|---|
| **#** | Final rank after re-ranking |
| **Source** | Which guide the chunk came from |
| **Section** | The section heading within that guide |
| **Cosine** | Raw similarity score from vector search (higher = closer match to your query embedding) |
| **Re-rank** | Arrow showing whether the chunk moved up (↑), down (↓), or stayed (=) after re-ranking |
| **Preview** | First few words of the chunk text |

Note: A chunk with a perfect cosine score (1.0) is not always the best answer — re-ranking considers the full question context, so other chunks may rank higher if they cover more of what was asked.

---

## Situation Heatmap

Below the sources table, the Situation Heatmap shows which situation types each retrieved chunk is tagged for:

- Each **row** is one retrieved chunk
- Each **column** is a situation type (Blocked, Conflict, Uncertainty, Momentum, Accountability, Clarity)
- **Color intensity** shows match strength — darker/brighter means a strong tag, faded means weak or no match

This explains why the Situation Filter matters. If you select "Accountability" before asking, chunks strongly tagged for Accountability are prioritized during retrieval — even before cosine scoring. The heatmap lets you see whether the retrieved chunks actually match the situation you care about.

## Tech

- Pure client-side HTML/JS — no backend, no server, no build step
- Embeddings and similarity search run entirely in the browser
- BM25 + cosine hybrid retrieval with a re-ranking pass
- BYOK: Anthropic API called directly from the browser using your key (`anthropic-dangerous-direct-browser-access` header)
- API key persisted in `localStorage` (try/catch wrapped for private-mode safety)
- Demo mode: pre-computed answers for 4 preset questions, zero API calls required
- No data is stored or sent anywhere except Anthropic's API

## Notes

- Answers are grounded only in the source guides listed above. If the guides don't cover something, the app says so.
- The "What the sources don't cover" section in each answer is intentional — it shows honesty about gaps rather than filling them with assumptions.
- The first time you load the app you'll see an onboarding prompt to pick your mode (Demo, BYOK, or claude.ai).
